# Changelog

## 1.1.0

- New look: the Jatify design. Glass panels, Norse titles and names, Averia descriptions, green actions; the character screen, every window (new world, modifiers, manage saves, add server, password, delete confirms, achievements, stats), new character and the loading bar.
- No longer needs SeneaL UI or SeneaL API. With Jatify UI installed Campfire takes its exact look; without it, the same layout in the design's colours with Valheim's fonts.
- Manage saves: one card per save that opens to its backups (Restore, move, delete) and actions, plus Open folder. Saved server passwords: Forget sits on the picked server.
- Unchanged: backups to campfire-backups before every delete, move or restore (nothing happens if that copy fails), and type-the-name deletes.

## 1.0.0

- First release: WoW-style character select with the party at the fire, worlds and servers on one screen, achievements and stats, new character, new world, modifiers, manage saves, add server, saved server passwords, loading bars, minimap cache for server joins, and backups before every save change.
- Works with SeneaL UI 1.2.5: its own character select and main-menu windows are switched off so Campfire's are used; its start screen stays.
